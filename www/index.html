Reset

The device leaves the bus after any of these. Reconnect to carry on.

MaskROM bootstrap

MaskROM accepts only two control transfers, 0x471 for DDR init and 0x472 for the USB loader. Load a packed loader to reach Loader mode. Luckfox ships this as MiniLoaderAll.bin beside update.img. This writes nothing to flash, and you can skip it if the image below carries its own loader.

Firmware image

Only the 102-byte header is read first, so a 400 MB file opens instantly. The embedded loader and the item table appear before anything is written.
