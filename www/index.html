Reset

The device leaves the bus after a reset; reconnect afterwards.

1 · Bootstrap from MaskROM

In MaskROM the chip only accepts two control transfers: 0x471 (DDR init) and 0x472 (USB loader). Load a packed loader (rk3506_spl_loader_*.bin) to bring the board up into Loader mode. Nothing is written to flash by this step.

2 · Firmware image

Pick an update.img. Only its header is read at first, so a large file is identified instantly. The embedded loader and the partition table are listed before anything is written.

3 · Write

Writing replaces the contents of the selected storage. Check the partition list below matches what you expect before starting.
